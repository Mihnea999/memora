# Developer work

- Toolkits: `memora-dev` installs and manages language toolkits (run `memora-dev` to see them).
- The Terminal is Ghostty: `open("Terminal")`. Run things yourself with `run_command` when the
  person just wants the result; open a terminal when they want to watch or work there.
- Projects live where the person keeps them (ask, or look in ~/Projects, ~/code, ~/src).
- git: read state with `git status`, `git log --oneline -10`; never force-push or reset --hard
  without asking.
- Long-running servers: start them in a terminal window, not with run_command (it waits).
- Claude Code is available from the App Store (AI section) for bigger coding work.
